# VALORIA ROLEPLAY STORE

واجهة المتجر + Backend حقيقي للطلبات (بدون قاعدة بيانات في هذه المرحلة).

- Discord: https://discord.gg/HvqxwsdSN
- السلة تعمل وتفتح.
- checkout يطلب إيميل اللاعب + حساب MTA + طريقة الدفع + رقم العملية.
- الطلب يُحفظ على الـVPS في backend/orders.json.
- لا يتم اعتبار الدفع مؤكدًا تلقائيًا؛ حالة الطلب تبدأ PENDING.
- قاعدة البيانات وربط MTA والتسليم الآلي تأتي بعد تثبيت الـBackend.
